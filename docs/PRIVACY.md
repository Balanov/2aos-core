# Приватность рыночных сигналов

## Что можно отправлять

Только структурированные агрегаты: код ниши, округлённое число наблюдений, округлённые диапазоны стоимости/времени, наличие класса интеграции, агрегированную срочность и фактические агрегированные результаты агентов.

## Что нельзя отправлять

Документы, сообщения, имена, контакты, ИНН/ОГРН, адреса, точные маршруты, секреты, свободный текст, уникальные идентификаторы, сырые логи, изображения, медицинские данные и любые значения, позволяющие выделить одну компанию.

## Правила экспорта

1. Явный opt-in владельца tenant; по умолчанию экспорт выключен.
2. Схема `default deny`: неизвестное поле отклоняет весь экспорт.
3. Локальная предварительная проверка и журнал дайджеста экспортируемого набора.
4. Не менее пяти независимых tenant в каждой публикуемой группе; малая группа остаётся локальной.
5. Округление величин и подавление редких сочетаний ниша/регион/отрасль.
6. Запрет повторного связывания: случайный export ID не содержит tenant ID и не является стабильным псевдонимом.
7. Отзыв согласия прекращает новые экспорты; удаление уже опубликованных агрегатов выполняется по export ID на стороне реестра.

K-анонимность снижает риск, но не является математическим доказательством невозможности реидентификации. Для чувствительных отраслей экспорт следует отключить или добавить независимую оценку риска и дифференциальную приватность на сервере агрегации.
