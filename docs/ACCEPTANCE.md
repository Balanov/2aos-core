# Матрица функциональной приёмки

Статусы: **CORE** — локальная реализация с автотестом; **ADAPTER** — требуется внешний сервис/учётные данные; **DATA** — требуется эталонный набор заказчика; **NOT CLAIMED** — результат нельзя гарантировать.

| Обещание | Проверяемый критерий | Граница |
|---|---|---|
| Локальная работа | `npm ci --ignore-scripts --offline` после наличия Node, запуск без интернета, SQLite, отсутствие телеметрии | CORE |

| Пулы и групповые чаты | Один запрос fan-out нескольким агентам, сохранённые ответы, bounded concurrency, остановка по epoch | CORE |
| 24/7 | Долговременная очередь, lease, retry, dead-letter, graceful shutdown, восстановление после рестарта | CORE; эксплуатационный soak-test отдельно |
| Автономно/с подтверждением | Дайджест действия, явное решение, идемпотентный commit, запрет выполнения до approval | CORE |
| OCR + IDP | Извлечение полей, контрольные суммы ИНН, сверка НДС/итога, OCR через локальный Tesseract | CORE; качество DATA |
| AI-оператор | Квалификация лида, состояние диалога, webhook телефонии, локальные STT/TTS-адаптеры | ADAPTER; full-duplex и конверсия DATA |

| ТОиР | Локальные пороги/аномалии телеметрии, forecast, приоритизированный draft work order | CORE + DATA |

## Что не выдаётся за доказанное

- 300 документов/мин, ≥99 % OCR, ответ за 2 секунды, ≥85 % целевых звонков, ≥95 % HR-скоринга и другие цифры сайта без эталонного испытания.
- Гарантированный доход, экономия ФОТ, трудоустройство, юридическая правильность или коммерческий результат.
- Работа внешней интеграции без её реального smoke-теста.
- Выполненное внешнее действие только на основании успешного HTTP/exit code: нужен проверяемый provider receipt или повторное чтение авторитетного состояния.
