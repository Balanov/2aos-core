# Changelog

## 0.2.0 — Host and developer exchange

- Consent-scoped cross-platform host inventory, metadata/content hashing and business classification.
- Native filesystem events with polling/diff fallback, added/changed/removed processing and RAG deletion.
- Exact process taxonomy for host observations.
- Read-only and owner-defined system profiles with bounded execution and approval/outbox for mutations.
- Privacy-approved developer briefs, JSON Schemas, acceptance criteria and `/.well-known/2aos.json` plus `llms.txt`.
- Cross-platform developer CLI with scaffold/pack/validate/submit/status/dashboard and Tab-enabled palette.
- Director submission accept → installation quote → approval → jobs → paid developer revenue.
- 53 automated tests, including full host and developer flows.

## 0.1.0 — Core

- 26 built-in agent types, durable orchestration, pools, artifacts and approvals.
- SQLite/RBAC/tenant isolation, billing, packages, partner/developer ledger and privacy gateway.
- Local models/RAG/OCR, SMTP, Telegram, WhatsApp and signed webhooks.
- 44 automated tests and CI on Linux/Windows.
